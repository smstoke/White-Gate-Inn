# The White Gate Inn

Static rebuild of the Framer site: `index.html` styled by `styles.css`, mobile menu in `nav.js`.
Fonts, images and logos are self-hosted under `assets/`.

```bash
npm run dev   # http://localhost:8000 with live reload (Node 20+)
```

Open items: the story and rooms photos are placeholders (the Framer site had none), and
the check-in and parking FAQ answers need real text.
